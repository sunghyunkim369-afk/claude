# 국내·해외 주식 추세추종 백테스트

EMA·ADX·MACD·RSI·거래량으로 추세 초입을 잡고, ATR 손절·트레일링 스탑으로 빠져나오는 전략을
과거 일봉으로 검증하는 프로젝트예요. 국내(원화)와 해외(달러)는 **환율 환산 없이 따로** 운용·계산해요.

## 실행

```bash
cd backtest
pip install -r requirements.txt
python main.py                 # config.yaml 설정으로 실행
python main.py --no-pandas-ta  # pandas-ta 없이 내장 지표 계산으로
python -m unittest discover -s tests   # 엔진 검증 (인터넷 필요 없음)
```

- pandas-ta 는 Python 3.12 이상에서만 설치돼요. 그 아래 버전이면 자동으로 같은 공식의 내장 계산을 써요.
- 결과는 `results/` 에 저장돼요: `summary.csv`(성과표), `trades.csv`(거래 내역), `equity_KR.png`·`equity_US.png`(자산곡선과 낙폭), `equity_by_symbol.png`(종목별), `equity_*.csv`.

## 규칙

| | 내용 |
|---|---|
| 매수 (모두 만족, 다음 날 시가) | 종가 > EMA60, ADX(14) > 25, MACD(12,26,9) 골든크로스, RSI(14) < 70, 거래량 > 20일 평균 |
| 매도 (하나라도) | MACD 데드크로스 → 다음 날 시가 / 손절: 진입가 − 2×ATR / 트레일링: 보유 중 최고가 − 3×ATR |
| 수량 | 손절에 걸리면 총자본의 1%를 잃도록 (ATR 기반), 한 종목 최대 25% |
| 보유 | 시장별 최대 5종목. 신호가 더 많으면 ADX 높은 순 |
| 비용 | 국내 매수 0.015%, 매도 0.015% + 거래세 0.18% / 해외 매수·매도 0.25% / 슬리피지 0.1% |

숫자는 모두 `config.yaml` 에서 바꿔요.

## 미래 데이터를 쓰지 않도록 한 방법

- 지표와 신호는 **그날 종가까지의 데이터**로만 계산하고, 주문은 **다음 날 시가**에 체결해요.
- 손절·트레일링 가격은 **전날까지의** 최고가·ATR로 정해 두고, 그날 저가가 닿으면 그 가격에 체결해요. 시가부터 그 아래로 갭하락하면 시가에 체결해요.
- 테스트로 확인해요: 데이터 뒷부분을 잘라도·크게 바꿔도 그 이전 지표·거래가 바뀌지 않는지 (`tests/test_backtest.py`).
- 지표 계산용으로 시작일보다 200일 앞 데이터부터 받아서, 시작일부터 바로 신호가 나올 수 있게 해요.

## 구조

| 파일 | 역할 |
|---|---|
| `config.yaml` | 종목·기간·지표·비용·리스크 설정 |
| `data.py` | 데이터 수집. 6자리 숫자는 국내(FinanceDataReader), 나머지는 해외(FinanceDataReader → 실패 시 yfinance) |
| `indicators.py` | 지표 계산 (pandas-ta, 없으면 내장 계산) |
| `strategy.py` | 매수·매도 신호, 손절·트레일링 가격 |
| `broker.py` | 주문 인터페이스. `SimulatedBroker`(백테스트), `KisBroker`(한국투자증권 API 확장 예시, `../trading/kis.py` 사용) |
| `backtest.py` | 백테스트 엔진, 매수 후 보유 비교, 성과 지표 |
| `report.py` | 표·CSV·차트 |
| `main.py` | 실행 |

## 결과 읽는 법

- **포트폴리오** 행: 시장별로 최대 5종목을 동시에 운용한 결과. B&H 는 같은 종목들을 첫날 똑같은 금액으로 사서 끝까지 보유.
- **종목별** 행: 그 종목 하나만 같은 규칙으로 운용한 결과. 수량 규칙(1% 위험, 최대 25%) 때문에 자본의 일부만 투자하므로, **평균투자비중**을 같이 봐야 B&H(항상 100% 투자)와 공정하게 비교할 수 있어요.
- 샤프지수는 일간 수익률 기준 연환산(√252), 무위험 수익률은 `report.risk_free`.
- 거래세는 연도마다 바뀌어 왔어요 (예: 2023년 0.20%, 2025년 0.15%). 기간에 맞게 `costs.KR.sell_tax` 를 조정하세요.
