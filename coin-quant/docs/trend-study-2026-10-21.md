## 0. 추세 판단 방법

기간 3개 × 근거 3개. 근거마다 −1/0/+1, 합이 +2 이상이면 '상승', −2 이하면 '하락', 나머지는 '횡보·불명확'. 매매할 때는 +2 이상에서 켜고 0 이하로 내려가야 끕니다(들락날락 줄이기).

| 기간 | 이동평균 (빠른선>느린선 + 느린선 상승) | 채널 위치 (최근 N일 고~저 중 위 40%/아래 40%) | 회귀 추세선 (기울기 방향, R² ≥ 0.3일 때만) |

| 중기 (몇 주~2달) | EMA 20/50, 느린선 5일 전보다 | 55일 | 50일 |

## 4. 결론: 며칠·몇 주·몇 달 추세를 모두 먹을 수 있나?

**짧게 답하면, 셋 다 먹으려 하면 오히려 셋 다 덜 먹습니다. 일봉으로 확인 가능한 건 '몇 주~몇 달' 추세이고, 며칠짜리는 사실상 못 먹었습니다.**

| 방식 (코어) | 며칠: 상승 포착 / 하락 맞음 | 몇 주: 상승 포착 / 하락 맞음 | 몇 달: 상승 포착 / 하락 맞음 |
|---|---|---|---|
| 단기만 | 0% / 53% | 55% / 33% | 65% / 42% |
| 중기만 | 0% / 50% | 34% / 34% | 76% / 38% |
| 장기만 | 0% / 0% | 12% / 49% | 64% / 27% |
| 아무 기간이나 상승이면 보유(OR) | 50% / 100% | 67% / 70% | 82% / 55% |
| 3단 분할(기간마다 1/3씩) | 17% / 45% | 37% / 43% | 65% / 32% |
| 3단 분할 + 장기 하락이면 단기 몫만 | 15% / 33% | 35% / 39% | 62% / 27% |
| 중기 보유 + 장기 하락이면 중단 | 0% / 0% | 27% / 25% | 72% / 27% |

1. **며칠짜리 추세(20일 이하)**: 대부분 방식의 포착률 중앙값이 0%입니다. 일봉 종가로 '상승'을 확인할 즈음이면 이미 상당 부분 올랐고, 빠질 때도 확인까지 하루 이틀 걸려 남은 몫을 돌려줍니다. 며칠짜리까지 잡으려고 '아무 기간이나 상승이면 보유'로 넓히면 상승은 50% 잡지만 하락도 100% 맞아서, MDD가 그냥 보유와 비슷해집니다.
2. **휩쏘(헛신호) 비용**: 단기 방식은 거래의 약 42%가 7일 안에 끝났고(BTC), 이 짧은 거래는 코어에서 거의 전부 손실이었습니다. 추세가 꺾여 점수가 0 이하로 떨어져야 나오는 구조라 '짧게 끝난 거래 = 틀린 진입'이기 때문입니다. 수익은 소수의 긴 거래(평균 보유 수십 일)에서 나옵니다.
3. **몇 주~몇 달 추세**: 몇 달짜리는 대부분 방식이 상승의 60~80%를 가져갔고, 몇 주짜리는 20~70%였습니다. 실제 수익은 여기서 나옵니다.
4. **기간을 섞는 방법**: 기간마다 1/3씩 나눠 담는 '3단 분할'은 세 기간을 조금씩 다 타는 대신 어느 하나도 크게 먹지 못하고, 장기 하락일 때 단기 몫만 남기는 변형이 MDD를 가장 크게 줄였습니다. '중기 보유 + 장기 하락이면 중단'은 거래가 적고(비용 낮음) 손익비가 높았습니다.
5. **기타(알트) 그룹**은 같은 방식이라도 성과가 코어보다 크게 낮고, 거래가 많아 비용 부담(연 3~8%)이 큽니다. 스윙의 중심은 코어로 두는 게 데이터와 맞습니다.
