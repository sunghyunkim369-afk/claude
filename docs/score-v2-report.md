# 점수식 개선안 검증 보고 (score-v2)

요청 프롬프트("무역나침반 점수 산정 방식 개선안을 검증하고, 조건이 맞으면 적용")에 대한 답변입니다.
작업은 GitHub `sunghyunkim369-afk/claude` 의 `score-v2` 브랜치에서만 했고, main·배포 사이트·사이트 데이터(data.js·latest.json)는 바꾸지 않았습니다.
`tradecompass-mvp/auth.js` 와 로그인 관련 파일은 건드리지 않았고, 비밀 값은 출력하거나 커밋하지 않았습니다.

**결론: 1단계 결과 제안식(v2)이 기존식(v1)보다 낫다는 근거가 없어서 2단계(SCORE_VERSION 플래그·공개 페이지 수정)는 하지 않았습니다.**
대신 1단계에서 찾은 분류·관련도 문제를 먼저 고쳤습니다(요청자 확인 후).

## 1. 현재 점수 계산 위치

| 내용 | 위치 |
|---|---|
| 점수식 `100 × (0.6·V + 0.4·M) × (0.6 + 0.4·R)` | `scripts/news/publish.js:200` (`main()` 안) |
| 기사 무게 (신뢰도 × 한국 관련도 × 최신성 반감기 3.5일 × 보도 언론사 수 × 의견 기사 0.5) | `publish.js:35` `weight()` |
| 보도량 V (같은 언론사 k번째 기사는 1/√k, 로그 정규화) | `publish.js:45` `volume()`, 정규화 :199 |
| 추세 M (이번 주 점유율 ÷ 직전 4주 점유율 → 0~1, 기사 수가 적으면 0.5 쪽으로 축소) | `publish.js:70` `momentum()`, 축소 :190 |
| 관련도 R (기사별 한국 관련도 평균) | `publish.js:186` |
| Top 10 선정 (대표 기사 기준 통과 → MMR·섹터당 3개 제한) | `publish.js:228` `eligible`, `:84` `pickTop()` |
| 대표 기사 관련도·선정 | `scripts/news/lib.js:222` `issueRelevance()`, `:239` `rankForIssue()` |
| 설정값 | `scripts/news/config.js` `SCORE` |

한 줄 설명: 보도량은 기사 무게의 합을 가장 큰 이슈 기준으로 로그 정규화한 값, 추세는 이번 주 비중이 평소(직전 4주)보다 얼마나 늘었는지를 0~1로 바꾸고 기사가 적으면 0.5 쪽으로 당긴 값, 관련도는 기사들의 한국 관련도 평균이며, 이를 `100 × (0.6V + 0.4M) × (0.6 + 0.4R)` 로 합칩니다.

## 2. 두 식 비교 (2026-10-05 ~ 10-12 주, 기사 227건, 이슈 후보 27개)

비교 스크립트 `scripts/score_compare.js` 는 publish.js 를 고치지 않고 같은 규칙으로 다시 계산합니다.
먼저 발행 당시 보관 파일(커밋 92366c5)로 v1 을 계산해 **발행된 Top 10·점수와 똑같은지 확인**했습니다.

### v2 를 적용하지 않은 이유
1. **작은 이슈가 Top 10에 들어옵니다.** 기사 2건·출처 1곳인 "일본 보조금·산업정책"이 들어왔고, 10-04 주에도 "보조금·산업정책"(2건, 출처 1곳)이 들어왔습니다. 제안식 V 에는 기사 수가 적을 때 0.5 쪽으로 당기는 장치가 없어 2건짜리 이슈가 V≈1.0 을 받습니다. 또 v2 점수 폭이 좁아(약 30~67, v1 은 53~73) v1 에 맞춘 MMR 다양성 벌점이 점수 차보다 커집니다.
2. **결과가 초기 가중치에 크게 좌우됩니다.** 0.5/0.3/0.2 를 ±0.1 바꾸면 v1 과의 상관이 0.667~0.918 로 흔들리고 Top 3 도 바뀝니다.
3. **v2 가 오분류를 걸러 내는 것은 아닙니다.** "경제제재"가 3위→10위로 내려간 것은 출처 수(4곳)·V 가 낮아서이고, 무역과 무관한 기사를 알아본 결과가 아닙니다. 두 식 모두 그 기사들을 그대로 셉니다.
4. 사람 판단과 비교한 근거가 아직 없습니다.

해석한 부분(확인 필요): R 은 "신뢰도 가중 기사 수 ÷ 227"을 후보 최댓값으로 나눈 값(같은 주 안에서는 227로 나눠도 순위는 같음), V 는 최신성 가중 점유율 ÷ 직전 4주 점유율(같은 출처 기준, v1 과 같은 평활), D 는 서로 다른 언론사 수입니다.

## 3. 대표 기사 불일치 목록과 원인 (후보 27개를 직접 읽고 판단)

| 이슈 | 대표 기사 | 판단 |
|---|---|---|
| 경제제재 | 보험광고 규정위반 … 협회 제재금 부과 10건뿐 | 불일치 |
| 공급망·핵심광물 | [바이오스냅] 동아쏘시오그룹, 협력사 대상 ESG 공급망 교육 | 불일치 |
| 미국 경제제재 | 노벨평화상 필라이, ICC 제재한 미국 규탄 | 애매 (나라의 제재지만 무역과 거리가 멂) |
| 해운·물류 | Freightmate admits using Flexport docs as AI trade secrets case settles | 애매 (영업비밀 소송) |
| 미국 공급망·핵심광물 | 두산에너빌리티, 美 스페이스XAI 공급망 진입 | 애매 (기업 납품 계약) |

- 분명한 불일치 2건, 애매 3건, 나머지 22건은 주제와 맞음. 대표 기사뿐 아니라 이슈 안에도 섞여 있었습니다: 경제제재 11건 중 8건이 공정위·금감원 제재나 담합, 공급망·핵심광물 16건 중 6~7건이 기업 ESG·금융·보안 뜻.

원인:
1. **분류가 단어 포함 여부만 봅니다.** "제재금"의 "제재", "ESG 공급망"의 "공급망"도 그 주제로 셌습니다.
2. **관련도가 단어 하나로 만점이 됩니다.** 주제 단어가 제목에 있으면 0.6, 상대국 없는 이슈는 0.3 을 그냥 받고, "제재"·"공급망"은 무역 핵심 단어 목록에도 있어 +0.1 을 한 번 더 받아 1.0 이 됩니다.
3. 진짜 무역 기사도 1.0 이라 동점이 되고, 그러면 무게(신뢰도·최신성)가 큰 **가장 최근 통신사 기사**가 대표로 뽑힙니다.

### 고친 것 (요청자 확인 후, `score-v2` 커밋 cd161e7)
- `config.js` `TOPIC_CONTEXT`: 제목에 제재금·과징금·공정위·담합·판매점·협회 등 / ESG·공급망 금융·공급망 보안·교육 등이 있으면 "제재"·"공급망"을 그 주제 단어로 세지 않음. "항만"이 들어간 관광·체육대회 기사, 영문 "trade secrets"도 제외.
- `lib.js` `issueRelevance()`: 상대국 없는 이슈는 다른 무역 단어가 제목에 있어야 0.3(요약에만 0.15), 주제 단어를 핵심 단어로 다시 세지 않음.
- 결과: 보관 기사 1,515건 중 31건 분류 변경, 이번 주 17건(모두 무역과 무관). 애매한 것 1건("수은, 아프리카개발은행과 광물 공급망 금융지원"). 위 불일치 2건과 Freightmate 건은 해소, 경제제재(상대국 없음)는 Top 10에서 빠짐. 10-04 주 Top 10 이슈 10개는 그대로.
- "무역 단어가 있어야만 센다"는 더 엄격한 방식은 요약 없는 정상 기사가 60건 넘게 더 빠져서 쓰지 않음.

## 4. 하지 않은 것, 확인하지 못한 것
- 2단계 전부(SCORE_VERSION 플래그, "순위 산정 방식" 페이지에 새 식·Baker·Bloom·Davis(2016)·Caldara 외(2020) 근거 추가)는 하지 않았습니다. 이유는 2절.
- 사람 순위가 없어 사람 기준 지표는 미측정입니다.
- 비교는 사실상 한 주(10-05~10-12)이고, 10-04 주를 보조로 확인했습니다.
- 불일치 판단은 제가 기사를 읽고 한 판단입니다.
- 남은 문제: "ICC 재판관 제재"처럼 무역과 거리가 먼 국가 제재, "공급망 진입" 같은 기업 납품 뜻은 아직 그대로입니다(경제제재에 넣을지 정해야 함).
- 사이트 데이터는 다시 만들지 않아, 수정은 main 에 합치고 다음 주간 발행 때부터 반영됩니다.
