# HS코드 쉽게 찾기

물건 이름을 입력하면 국제 공통 HS코드(6자리, HS 2022 기준)를 알려주는 단일 HTML 페이지입니다.
성분이 섞였거나 구성이 복잡한 물건은 전문가 확인이 필요하다고 안내합니다.

## 실행 방법

별도 설치 없이 `index.html`을 브라우저로 열면 됩니다.

## 참고

- 표시되는 코드는 참고용 6자리입니다. 실제 수출입 신고에는 국가별 10자리 코드(한국은 HSK)가 필요하며,
  [관세법령정보포털(CLIP)](https://unipass.customs.go.kr/clip/index.do)에서 확인할 수 있습니다.
