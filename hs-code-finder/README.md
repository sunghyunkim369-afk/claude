# HS코드 쉽게 찾기

물건 이름을 입력하면 국제 공통 HS코드(6자리, HS 2022 기준)를 알려주고,
품목별 질문으로 코드를 좁히는 단일 HTML 페이지입니다.

## 코드 좁히기 질문

섞였는지를 묻는 대신 품목분류 원칙대로 "무엇이 주인지"를 물어요. 답을 고르면 코드가 바로 바뀝니다.

- 의류: 니트(편물)·직물 여부, 무게 기준 가장 많은 섬유, 남성·여성용 (61류 ↔ 62류, 6109.10 ↔ 6109.90 등)
- 신발: 겉감(갑피)·밑창 재질, 운동용 여부 (6402 · 6403 · 6404)
- 가방·지갑: 겉면 재질 (인조가죽은 플라스틱 시트로 분류)
- 그 밖: 스마트워치 통신 여부, 전기자전거, 모니터 TV 튜너, 믹스커피, 조미김, 코코아 함유, 도금 장신구, 스파클링 와인 등
- 모든 품목 공통: 단품 / 소매용 세트 / 기계 부품 여부. 부품이면 전문가 확인을 안내

질문과 분기 규칙은 `index.html`의 `Q`, `REFINE`, `GROUP`에 있습니다.

## 관세 · 세금 계산

- **개인 직구**: 소액 면세 판정(미국발 목록통관 200달러, 그 외·식품·화장품 150달러, 주류는 면세 없음) 후 관세·부가세 계산
- **사업 수입**: 원산지 국가를 고르면 한국과 맺은 FTA·특혜관세 협정 목록(발효 연도, 원산지증명 발급 방식)을 간단히 보여주고, 품목별 협정세율은 FTA 홈페이지·관세청 FTA 포털에서 확인하도록 안내합니다. 확인한 세율을 넣으면 기본세율과 비교해 절감액을 보여줍니다.
- **사업 수출**: 수출 대상국의 협정 목록과 원산지 기준·증명 절차 체크리스트를 보여주고, 상대국 일반 관세율과 확인한 협정세율을 넣으면 상대국 관세가 얼마나 줄어드는지 계산합니다.
- 주세·교육세(주류), 개별소비세·교육세(200만원 넘는 가방·귀금속), 관세 징수 최저한(1만원 미만)을 반영

### 협정 데이터

- 협정 목록과 원산지증명 방식은 `AG`, 국가별 적용 협정은 `PARTNERS`에 있습니다. 2026년 기준으로 정리했으며, 최근 발효·서명된 협정은 관세청 자료로 확인이 필요합니다.
- 협정세율은 화면에 싣지 않고 FTA 홈페이지로 안내합니다(링크는 `FTA_LINKS`). 나중에 공식 자료를 `FTA_RATES`(`{ "HS 6자리": { 협정id: 세율 } }`)에 넣으면 수입 화면의 협정세율 칸이 가장 낮은 값으로 미리 채워집니다.
- 협정세율은 대부분 매년 1월 1일에 바뀌므로 매년 한 번 갱신하고, 2027년 1월 HS 개정 때 코드 연결을 다시 확인해야 합니다.

기본세율과 환율은 참고값이며 화면에서 직접 고칠 수 있습니다. 실제 세율은 HSK 10자리 기준으로 CLIP에서, 환율은 관세청 고시환율로 확인하세요.

## 실행 방법

별도 설치 없이 `index.html`을 브라우저로 열면 됩니다.
