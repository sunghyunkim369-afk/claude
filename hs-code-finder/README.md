# HS코드 쉽게 찾기

물건 이름을 입력하면 국제 공통 HS코드(6자리, HS 2022 기준)를 알려주는 단일 HTML 페이지입니다.
성분이 섞였거나 구성이 복잡한 물건은 전문가 확인이 필요하다고 안내합니다.

## 예상 세금 계산

품목을 고르면 상세 화면에서 예상 세금을 계산할 수 있습니다.

- **개인 직구**: 소액 면세 판정(미국발 목록통관 200달러, 그 외·식품·화장품 150달러, 주류는 면세 없음) 후 관세·부가세 계산
- **사업 수입**: 가격조건(FOB/CIF), 운임·보험료 반영, 원산지별 FTA 협정세율을 입력하면 기본세율과 비교해 절감액 표시
- 주세·교육세(주류), 개별소비세·교육세(200만원 넘는 가방·귀금속), 관세 징수 최저한(1만원 미만)을 반영
- 기본세율과 환율은 참고값이며 화면에서 직접 고칠 수 있습니다. 실제 세율은 HSK 10자리 기준으로 CLIP에서, 환율은 관세청 고시환율로 확인하세요.

## 실행 방법

별도 설치 없이 `index.html`을 브라우저로 열면 됩니다.

## 참고

- 표시되는 코드는 참고용 6자리입니다. 실제 수출입 신고에는 국가별 10자리 코드(한국은 HSK)가 필요하며,
  [관세법령정보포털(CLIP)](https://unipass.customs.go.kr/clip/index.do)에서 확인할 수 있습니다.
