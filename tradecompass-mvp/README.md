# TradeCompass MVP

TradeCompass 대시보드 구성을 무역나침반(크림·네이비·황동) 색감으로 옮긴 정적 MVP입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 동작합니다.

## 화면

| 화면 | 주소 | 내용 |
|---|---|---|
| 대시보드 | `#/` | Today's Bearing(오늘의 요약), 섹터별 노출도, 핵심 무역 이슈, 공급망 리스크, 뉴스 × 연관 종목, 국가·품목별 무역 흐름 |
| 무역 뉴스 | `#/news` | 태그 필터가 있는 뉴스 × 연관 종목 목록, 핵심 이슈 전체 |
| 섹터 분석 | `#/sectors`, `#/sectors/<id>` | 섹터 목록, 섹터를 누르면 이 섹터의 Top10 이슈(점수·보도 건수 변화·조치 방향·대표 기사)와 종목 정렬 결과 |
| 관심 섹터 | `#/watch` | ★로 고른 섹터 모아보기 (브라우저 localStorage에 저장) |
| HS 코드 · 통관 계산 | `#/hs` | `../hs-code-finder` 페이지를 불러와 HS 코드 검색과 예상 세금 계산 |

## MVP에서 뺀 것

실시간 연동이 필요한 기능은 제외했습니다.

- 지수·환율·유가 실시간 시세, 종목 실시간 차트와 등락률
  - 종목 영향은 가격 대신 AI가 판단한 방향(긍정/부정/중립)으로 표시
- 운임 조회, 화물 추적 (메뉴에 "준비 중"으로 표시)

## 데이터 채우기

화면에 보이는 내용은 모두 `data.js`의 `window.TC_DATA` 한 곳에서 옵니다.
AI 파이프라인이 하루 한 번 같은 구조로 이 파일을 새로 만들어 덮어쓰면 됩니다.
현재 값은 샘플이며, `meta.sample`을 `false`로 바꾸면 상단의 "샘플 데이터" 표시가 사라집니다.

| 키 | 내용 |
|---|---|
| `meta` | 기준일, 갱신 시각, 수집 뉴스 수 |
| `bearing` | 오늘의 한 줄 요약과 핵심 포인트 |
| `sectors` | 섹터별 노출도(0~100, 50 = 중립), 상태(강화/보합/완화), 강화·완화·중립 건수, 요약, 연관 종목 |
| `issues` | 핵심 이슈: 키워드, 영향도(0~100), 이슈 점수, 최근·직전 7일 보도 건수, 조치 강화·완화·중립 건수, 관련 섹터 id, 대표 기사 |
| `news` | 뉴스, AI 요약, 연관 종목별 영향 방향(`up`/`down`/`flat`) |
| `risks` | 공급망 리스크 신호(심각/주의/관찰) |
| `trade` | 월간 수출 총액·증감·수지, 국가별·품목별 금액(십억 달러) |

## 애니메이션

화면 등장 시 카드가 순서대로 떠오르고, 나침반 바늘이 노출도 방향으로 회전하며, 숫자는 카운트업, 막대는 차오르는 효과가 있습니다.
운영체제에서 '동작 줄이기'를 켠 사용자에게는 애니메이션 없이 바로 표시됩니다.
